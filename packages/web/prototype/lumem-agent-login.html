O rodapé da sidebar pedia nome, transporte, comando, argumentos e versão do adaptador — cinco campos que só quem mantém o próprio adaptador sabe responder. Casos

Quatro situações em que login com um clique não resolve sozinho. Nenhuma delas volta a pedir comando por padrão — a única que mostra terminal é a que o próprio adaptador exige.

Quando não há navegador na máquina do daemon

Em SSH ou container, o adaptador troca os métodos: some o login por navegador e sobra claude-login, que pede o terminal daquela máquina. O Lumem abre esse terminal para você em vez de mandar você procurá-lo.

De onde a tela tira o que mostra

Nenhum botão desta tela é lista fixa nossa. Os jeitos de entrar chegam no initialize, e o Lumem só desenha o que o agente disse que aceita — por isso a mesma tela serve para qualquer agente ACP, hoje e depois.

Tela ↔ protocolo

Na telaNo ACPQuem decide
Lista de jeitos de entrarinitialize → authMethods[] com id, name, descriptiono agente
Clique em "Entrar com a assinatura"authenticate({ methodId: "claude-ai-login" })a pessoa
"Anthropic Console"authenticate({ methodId: "console-login" })a pessoa
"Abrir um shell em build-01"claude-login — método que o adaptador só oferece sem navegadoro ambiente
Painel abre sozinhosession/new respondeu auth_requiredo agente
Botão "sair"só existe se veio agentCapabilities.auth.logouto agente
Comando, args, versãonão é ACP — é config do daemon, e ele preenche sozinhoo daemon

Ordem real: initialize → (se preciso) authenticate → session/new. O painel de login nasce dessa segunda etapa, e some assim que ela passa.

O que saiu do caminho

Campo NOME O nome era rótulo interno de uma config global. O agente já tem nome: Claude Code. Some.
Campo TRANSPORTE Havia uma opção real (conversa ACP) e uma legada (terminal). Escolher transporte é escolher se a sessão tem cartão de ferramenta — decisão do produto, não do usuário.
COMANDO e ARGUMENTOS Só quem mantém adaptador sabe responder. Vira gaveta avançado, fechada.
VERSÃO DO ADAPTADOR Continua fixada — e continua importante —, mas quem fixa é o daemon. Aparece como fato em avançado, não como campo a preencher.
Entrou: estado de conexão no rodapé Uma linha com pip: nenhum, entrando, conectado, expirado, falhou. Antes não havia onde ler isso.
Entrou: instalação automática, visível O adaptador é instalado pelo daemon, na pasta do app, com versão fixa — e o progresso aparece em três linhas em vez de um comando para copiar.

Regras que este fluxo assume

Um preenchido por painelO caminho que serve para quase todo mundo. Os outros são contorno e link.
Segredo nunca na telaChave aparece mascarada, vai para o chaveiro do sistema, e nunca é ecoada de volta.
Quem confirma é o agenteNão existe botão "já entrei". O painel troca de estado quando o authenticate volta.
Sem modalO painel mora na coluna e empurra a árvore. A sessão que estiver rodando continua visível ao lado.
